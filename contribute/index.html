Help build Lifecycle Practice

These are free games that teach the judgment calls of lifecycle marketing. They get better when people who do the job put their experience into them. Pick whatever fits the time you have. Most of these need no coding.

1

Tell me what you think

5 minutes · no account

Play any part of the game and press Make a suggestion (top right). Pick Bug, Feature idea or Feedback and write a line or two. It goes straight to the list of open issues. "This step confused me" helps as much as a bug report.

Play the game →
2

Talk it through with me

15 to 30 minutes · a DM or a Zoom call

The best levels come from real work. If any of these sound like you, message me:

  • You have a marketing story: a launch that broke, a flow that quietly stopped working, a test that fooled everyone.
  • You found something clever at work: a segment, a test setup, a report that saves you time every day.
  • You want to teach this, or you're learning it and know what was hard.

We talk it through and I turn it into a level. You get credit in the game, by name or not, your call.

Message me on LinkedIn →

15 minutes · no coding

Describe one change the way you'd ask an AI coding agent (Claude Code, Codex, Cursor) to make it, and say how to check it worked. I read every one and choose whether to run it. If I do, I link the change back to you.

Build it yourself
an evening or a weekend · GitHub
    
Fork the repo and build a new level, a new step, a fix or a whole game mode. Then open a pull request that says what you built and includes a review link (below), so I can try it in one click.

    
Building with an AI agent? Point it at AGENTS.md first. It has the layout, the rules and what to hand back.

What's being built next


The project board shows what's up next and what's in progress. Anything in Up next is open to pick up. Say so in the issue first so two people don't build the same thing. Issues marked good first issue are small on purpose.



Run it on your computer


There's nothing to install and no build step. You need Python 3 (or any static web server):


git clone https://github.com/YOUR-NAME/lifecycle-practice
cd lifecycle-practice
python3 -m http.server 8000


Then open http://localhost:8000. Reload the page to see a change.



Review links


A review link is a full web address that opens the game right at the thing you changed, so the reviewer clicks once and is there. Put one in every pull request, written out in full. If you build with an AI agent, it writes these for you (AGENTS.md tells it how). Review links use a separate practice save, so they never touch anyone's progress. Try these:

The rules every change follows


    
  
  • One new thing per step. Teach one idea, practise it alone, then join it with what came before.
    • 
  
  • Every screen asks for a decision. No screens that are only reading.
    • 
  
  • The tool screens look like the real tools, so practice carries over to work.
    • 
  
  • Made-up numbers and made-up people only. No real company's data.
    • 
  
  • No AI calls and no accounts. The game runs entirely in the browser.
    • 
  
  • Plain words, short sentences.
    •
